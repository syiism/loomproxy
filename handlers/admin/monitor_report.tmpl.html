日界口径：一天从几点开始只由 utils.DayStart 定义（待办清单 P71/P72）， 分桶在 Go 侧按平台时区完成——不在库里用 date(created_at) 判， 因为 SQLite 会把带 +08 的串先归一到 UTC 再取日。

因此在开发/测试的 SQLite 库里，北京时间 00:00–08:00 这段量会挂到前一天的柱子上； 生产 MySQL（loc=Local）与平台时区一致，无此症状。看到第一根柱子偏高时先想这一条。

成功判据：HTTP 2xx 且非带内失败（P22，正文是错误载荷的 200 算失败）； 库里 in_band_error 为 NULL 的旧行按纯 HTTP 口径算成功。
