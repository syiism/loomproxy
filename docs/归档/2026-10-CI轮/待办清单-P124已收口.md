## P124 `RankCacheSec` 声明了、有人读、**没人装配**：P118 ③ 那颗缓存装了等于没装【已收口（2026-10-23：`RankCacheSec` 装配行补齐、双用例+变异三红、`config-wired-check` 进门禁，commit `3a32651`）】

- **症状（写发布单时顺手核出来的，不是有人报的）**：为了准备"新产物确实带着 P118 ③"的字面量互证，
  在二进制里 `grep -a -c 'RANK_CACHE_SEC'` → **0**；顺着查 `conf/conf.go`：字段声明在第 116 行、
  读取方在 `handlers/rank/rank.go:231`（`ttlSec := conf.Config.RankCacheSec`），
  但 `Load()` 的装配块（250-320 那一片 `envInt(...)`）**没有 `RankCacheSec:` 这一行**——
  全文 `grep -n` 命中数 = **0**。
- **影响**：Go 给未赋值字段的是零值 `0`，而这一位 **0 的业务语义恰好是"每次真算"**（注释自己写的）。
  于是 P118 ③ 那次"给公开榜加缓存"的改动**在生产里完全不生效**：现网 p50 522ms / p90 1.49s 那两趟主聚合照旧每次都跑。
  三处文档同时说假话：`.env.example` 的 `RANK_CACHE_SEC=60`（改了没用）、
  AGENTS §9 那句"默认 60 秒"（不成立）、本报告 §14 的"有默认 60，不写也成立"（也不成立）。
- **为什么四条榜用例一条都没抓到**（这是本条真正的教训）：它们都写成
  `prev := conf.Config.RankCacheSec; conf.Config.RankCacheSec = sec; defer 还原`——
  **测的是"值怎么用"，那条通路根本不经过 `conf.Load()`**。
  判据页《断言空转》那一族的"读的是测试脚手架的零值"这一形，在这一位上**第二次成立**
  （第一次是 `MONITOR_RETENTION_DAYS` 那条，见 `test/conf_env_notice_test.go` 页头的自述）。
- **已做的（本轮，同一次提交里）**：
  ① `conf/conf.go` 补上 `RankCacheSec: envInt("RANK_CACHE_SEC", 60),`，并在字段与装配两处都写明这一格曾经缺；
  ② 用例两条腿：`TestEnvDocumentedDefaults` 里加 `RankCacheSec` 那一格（**走真 `conf.Load()`**，钉默认 60），
  新加 `TestRankCacheSecEnvKeyActuallyReachesTheField`（未设置=60 / 写 120=120 / 写 0=0）——
  **第二腿单独存在是因为只钉默认挡不住"键名拼错"**：装配块写成 `RANK_CACHE_SECONDS` 时默认照样 60、第一腿照样绿。
  ③ 固化成门禁检查 `scripts/check-config-wired.sh`（接进 `make vet`）：数 `ConfMgr` 的字段，
  每一个都必须有写入方（装配块字面量或 `Config.X =` 后置赋值），漏一个即构建红。
  **它是 `settings-readers-check` 的镜像**：那一头管"设置键没人读"，这一头管"配置字段没人装配"。
- **变异验证**（三次，各红一处）：删掉装配行 → 用例两条腿与那条新检查**同时红**（检查会点名 `RankCacheSec`）；
  键名改成 `RANK_CACHE_SECONDS` → **只有第二腿红**（第一腿绿——这就是它存在的理由）；
  检查脚本自身在修复后的树上跑 = **56 个字段、漏 0**（上线时零假警报，这条是它能不能活下来的前提）。
- **档位**：判据页不新立一行——《断言空转》那一行补第 ⑬ 种失灵（**用例绕过装配通路，直接改全局**），
  机器面已经由 `config-wired-check` 接住；本轮 `make vet` 新增检查数 = 2（`script-syntax-check` 与这一条），
  **门禁闸的名额用到上限**。
- **被它阻塞的条目**：P118 ③ 的"已上线"这句在修复之前不成立；现在成立但要等下一次换装才在线。
- **发现处**：2026-10-10 写发布单第 3 步时，准备拿字面量互证验产物新旧，第一个砝就选了 `RANK_CACHE_SEC`——
  **它不在二进制里，于是顺着往下查而不是先怀疑砝选错了**（这一步走对了：换装三查那句"读数要来自被测对象本身"）。
