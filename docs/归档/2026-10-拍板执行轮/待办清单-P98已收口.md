## P98 环境变量的非法值静默回落到默认值，而回落方向恰好最危险：`AUTH_ENABLED=1` 是关、`MONITOR_RETENTION_DAYS=1y` 是永久保留【已处理】

- **状态**：已处理 `07fb9d8`（第三十四遍巡检撞出；`make build` 全绿 `MAKE_EXIT=0`，三次变异各自把用例打红）。
- **现象/证据**：`conf/conf.go` 的三族解析器把「填了但不认识」和「没填」当成同一件事——
  `envInt` 里 `strconv.Atoi` 失败就 `return def`、`envFloat` 同形、`envBool` 是
  `strings.ToLower(v) == "true"`（于是 `1`/`yes`/`on`/拼错的 `ture` 一律 **false**，连"这不是个布尔"都不说）。
  全仓非用例的 `time.Duration(...)` 换算点 23 处逐条对过单位（没有秒/毫秒错），
  顺着「填进去的值有没有被按填的样子接受」把三个解析面对了一遍：设置侧（P60/P61/P63，写入口校验 +
  读取口各一处 + `check-setting-readers.sh` 两条规则）✓、请求参数侧（`utils.Paginate` + 绑定错误固定句，
  P86/P90②）✓、**env 侧 ✗**。
- **影响**（两位都不是"填错一个数"，是"以为开着其实关着"）：
  - `AUTH_ENABLED=1` → false。P64 写的是「网关关了不等于谁都不认」，这一条是它的镜像：
    **你以为没关**。而且方向上它会顺带躲过「默认 `JWT_SECRET` + 启用鉴权 = 拒绝启动」那道保护——
    那道门只在 `AuthEnabled` 为真时立。
  - `MONITOR_RETENTION_DAYS=1y` → 0＝永久保留且不清理，正好把 P54 那一格在报的「只进不出」打开；
    症状要到表长起来才看得见，而那时没人记得三天前改过 `.env`。
  - 同族判据早就存在（P60 在设置写入口直接拒 `1`/`yes`、P48 要求「填了没生效要出声」），
    **只是没人把它应用到 env 上**——「同一个判据在几个包里各写一份，修好一处时另两处没人知道」那条的又一实例，
    这次漏的那一份连一份都没写。
- **顺手拆掉一处假绿灯**：`test/monitor_retention_test.go` 里那句
  「`MONITOR_RETENTION_DAYS` 默认应为 0（永久）」读的是**脚手架**的 Go 零值
  （`setupTestConf` 的结构体字面量没写这个字段），把 `conf.go` 的默认改成 7 它照样绿。
  已改名 `TestCallLogRetentionDisabledWhenZero` 并把话说明白，产品默认那根钉子移到
  `test/conf_env_notice_test.go` 的 `TestEnvDocumentedDefaults`（跑解析器本身，改默认就红）。
- **修法**：语义一个字不动（布尔仍只认真正的 `true`，数字非法仍用默认），只做两件事——
  ① 三族解析器把「填了但没被按填的样子接受」的键攒进 `badEnvNotes`；
  ② `Load()` 在**判 JWT 之前**一次一条 `WARNING: 环境变量 …` 出声（顺序反了的话 `AUTH_ENABLED=1`
  会顺带躲过那道默认密钥保护，而那句"你的 1 没被当成立即"正是它该先听到的）。
  **不当场拒启动**：那是把开发环境一起锁在外面，填错的人需要的是那句话，不是一堵墙——
  这一句是它与 P60（设置写入口 400）唯一的差别，写在代码注释里而不是只在这里。
  只有这三族会出声：凭证走 `envStr`/`envList`，没有"非法值"概念，因此原始值不会进日志（P62 同判据）。
- **验证**（`scripts/mutate-restore.sh`，三次都红、还原后逐字节核对）：
  ① `case "true":` 改成认 `1` → 红（钉的是"语义没被改宽"这半句）；
  ② 摘掉 `envInt` 里那句 `noteBadEnv` → 红（钉的是"出声"那半句）；
  ③ `envInt("MONITOR_RETENTION_DAYS", 0)` 改成 7 → 红（钉的是文档化默认）。
  另含一条**反向**断言：合法的 `POOL_MAINTAIN_SEC=90` 不许出声——门禁变噪音的那天，下一个人就开始无视它。
- **文档**：`docs/架构/弹性获取栈与环境变量.md` 的环境变量段首加了「填了但没被按填的样子接受会出声」
  一节（含"默认值的钉子只有一处"那句，防止再长出第二份默认值表）。
- **没上门禁**（写明为什么）：要拦的是「某个 env 键的默认值与文档不一致」，静态扫得新建一张默认值表，
  那张表本身就是第二份事实来源；代价大于收益，用例钉解析器 + 文档钉措辞够了。
