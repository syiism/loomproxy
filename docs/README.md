## 提交纪律

- `docs/` 已纳入版本管理（此前被 gitignore 忽略）。**凭证、卡密明文、可直接上线的真实 `.env` 不进 `docs/`**——
  它们留在被忽略的 `.qoder/` 或部署机上。
- 代码改动落地后，同步更新对应主题页（不是把细节写回 AGENTS.md），与代码一起提交。
