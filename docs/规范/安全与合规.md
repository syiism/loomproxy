# 安全与合规

> 本页由 `AGENTS.md` §11 拆出（2026-10-01 文档瘦身）。AGENTS 只留条目与一句话总结，细节以本页为准；
> 代码永远是最终事实来源，与本页冲突时以代码为准并回来更新本页。

- 不要把真实密钥写入仓库或文档：`.env` 的 `API_KEYS`·`ADMIN_PASSWORD`·`JWT_SECRET` 均属敏感信息；生产必须改默认 `JWT_SECRET`。
- CORS 当前为 `*`（面向阅读 App 的开放 API），收紧前需评估对书源客户端的影响。
- `baseURLCheckMiddleware` 对所有注册路由校验 `base_url`（`utils.IsSafeURL`：仅 http/https，DNS 解析后拒绝回环/私有/保留 IP，含 IPv6）。**按来源区别对待**：请求参数与用户个人配置严格校验；**平台默认配置视为管理员可信来源**，允许指向本机/内网（用于同机部署数据源项目）。声明 `FixedBaseURL` 的源整体跳过。
- 密码 bcrypt 哈希；用户软删除，其用户名/邮箱进入黑名单（注册、建用户、管理侧改邮箱三处查重都走 `Unscoped()`
  且改邮箱排除自身 id，冲突返回 409 提示「已被注销账号占用」；少一处预检，约束冲突就一路撞到驱动变成没头没尾的 500。
  占用者用户号只在 `/admin/users/:id` 的文案里给出——注册端是匿名可达的，不能泄漏他人 id）。
  `users.email` 声明 `not null`：历史 NULL 行只读，管理端提交空邮箱一律 400 而不是写 NULL。
- 号池与设备凭证（`pool_devices.attrs`）属上游签名凭证：接口响应与日志只出脱敏值（保留前 8 后 4），管理面板不展示原值。
- **登录防爆破的锁定读数只经 `/admin/*`，且不新增留存**（待办清单 P40）：`GET /admin/security/attempts` 出的是
  当前进程内存里的「IP + 窗口计数 + 是否锁着」，`POST /admin/security/attempts/reset` 按 IP 清锁——两者都不写库、
  不进 `api_call_logs`（那张表只覆盖数据源路由）。选择「不落库」是有意的：把每次登录尝试（IP + 用户名）长期驻库
  是一份新的敏感行为留存，需要单独的保留期与出明细口径，不该顺带塞进一个运维按钮。
- **阅读数据的留存同意位**（待办清单 P37）：`users.content_consent`，NULL = 从未表态 = **同意**（默认档写在读的一侧，不靠回填数据）。
  用户在个人中心（`/panel` → 个人资料 → 阅读数据留存）可关闭；关闭后 `monitor` 在写入明细之前抹掉
  搜索词、书名、章节名、**书目标识与章节标识**、媒介、结果数七个字段——标识必须一起清，
  否则名称回填循环会按标识把书名补回来，开关形同虚设。请求本身照常成功、调用计数不受影响。
  承诺的边界要说全：**留存的内容只用于排行榜展示，公开端点只出书名与搜索词**（维度白名单
  `keyword`/`book`，章节与媒介不出公开榜，身份字段更不给）；关闭**不追溯删除**已落库的历史明细，
  「删除我的全部记录」是另一个决策（涉及审计口径与既有备份）。
  同意位只有 `POST /auth/privacy` 一个写入口，且**只认会话**：长期 API Key 能改它，
  就等于密钥泄露时攻击者可以替受害者重新打开留存，而这件事在会话列表里看不见。
- **许可与合规**：代码按 AGPL-3.0 发布（`LICENSE`），使用条件见 `DISCLAIMER.md`。引入新依赖前确认许可证与 AGPL 兼容（`go.mod` 是唯一的依赖清单，别绕过）；不要把凭证、上游签名参数或真实 `.env` 内容写进仓库、文档与测试夹具。`api_call_logs` 的内容维度是用户阅读/调用行为数据，默认永久保留（`MONITOR_RETENTION_DAYS=0`），对外部署前必须按合规要求设定保留期。
- **调用明细含用户阅读内容**（搜索词/书名/章节名/媒介）：属敏感行为数据，**明细**只经 `/admin/*`（后端 `AdminRequired()`）暴露给管理员，不进访问日志、不出网关；
  管理员可按**数据源**把**聚合榜**（`/rank/boards`：两个维度、top20、只有名称与次数）放开给登录用户
  （`rank_public_sources`）——
  聚合不等于明细，但窗口越短稀有词越容易反推到个人，所以公开端的窗口取值被代码钉死为 1/7/30 天且不接受更细的筛选；默认永久保留（`MONITOR_RETENTION_DAYS=0`）意味着这些记录长期驻库——对外部署前按合规要求设定保留天数。
- 面板路由守卫在前端，真正可信的权限校验是后端 `AdminRequired()`——后端是唯一信任边界。
