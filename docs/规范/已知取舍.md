# 已知取舍

> 本页由 `AGENTS.md` §12 拆出（2026-10-01 文档瘦身）。AGENTS 只留条目与一句话总结，细节以本页为准；
> 代码永远是最终事实来源，与本页冲突时以代码为准并回来更新本页。

- 处理器间传参用 `map[string]interface{}`（换取统一的 Legado 形状与低接入成本，牺牲部分类型安全与性能）。
- SSRF 的 DNS 结果永久缓存在内存中（无过期）。
- 缓存预热：启动约 2 秒后预填充 `/datasources`（匿名视图）的缓存（30 秒超时；`db.Init` 失败时跳过）。`/data` 不预热也不缓存——它每次直读文件（待办清单 P16）。
- `/datasources` 走 Redis 缓存，管理端相关写操作（数据源 CRUD、套餐的 `scope=source` 限额增删、用户套餐变更、兑换）调用 `InvalidateDatasourcesCache()` 写时失效（`/data` 不缓存，见待办清单 P16）。
- **`/datasources` 的鉴权口径与 `/data` 不同**：默认白名单是 `/,/data,/auth/register,/auth/login,/panel`，而 `IsWhitelisted` 的匹配是「全等或按 `/` 分段的真前缀」（`path == wl || strings.HasPrefix(path, wl+"/")`），所以 `/data` 这条**不**顺手放行 `/datasources`。`AUTH_ENABLED=true` 时匿名拉 `/datasources` 实测 401（待办清单 P8）；要让书源客户端匿名拉清单，是管理员把它加进 `AUTH_WHITELIST` 的产品决策，不是文档里的默认。
- **`quota_plan_data_sources` 是弃用表，但仍留在库里（AutoMigrate 照建）**：授权已经并进限额表
  （`quota_limits(scope=source)`，待办清单 P34），运行期不再读写它，只有 `alignPlanGrants` 在启动时把存量行搬一次。
  不立刻 `DROP` 是取舍——删表要一次带备份的 DDL 发布，而代码回滚和数据回滚耦在一起；
  留在库里也不会有人再写它，因为判定口只有 `gate/grant.go` 一处，用例 `TestLegacyLinkTableGrantsNothing` 盯着它。
- 配额计费按**请求**计数，含上游缓存命中；如需按上游真实调用计费需另改。
- `docs/` 里的激进方案（unsafe 字段映射、工作窃取调度等）不落地。
- 仓库有远端（`origin = git@gitee.com:syiism/loomproxy.git`，`main` 跟踪 `origin/main`）、无 CI：构建纪律靠 Makefile，部署靠 `scripts/deploy.sh` 与 Dockerfile，受保护路径校验靠本地基线 tag 的三点 diff。**推送策略**：`main`（基座，公开）可由维护者推送；携带数据源的 `sources/*` 分支暂不推送远端。
- 历史 Python 版设计文档在 `docs/`；`test/python/` 是 auth/quota 用例的 pytest 黑盒移植版（uv 管理）。
  移植版起的是真实子进程，而底座产品二进制不带数据源，故用例打的是 `cmd/fakegateway`（假源 `fake_a`/`fake_b`/`fake_c`）；harness 每次会话重建该二进制，`LOOMPROXY_BIN` 可指向自备的产物。
