## 3. P118 ③：公开榜缓存（本轮第一颗动线上行为的提交）

- **做法**：在 `handlers/rank` 的**出口层**缓存「要发出去的那两张榜的行」，TTL 走新的环境变量
  `RANK_CACHE_SEC`（默认 60，<=0 每次真算）。键的原料：`admin` / 排序后的 `allowSources` /
  `days` / **`WindowStart(days)` 的 Unix** / `source` / `media` / `limit` / `dims`（由 `boards` 现算）。
  前缀分两段 `rank:boards:all:` 与 `rank:boards:pub:`，公共段由导出的 `BoardsCachePrefix` 单点供给
  （用例也从它取，不在测试里抄键的拼法——P39 那一族）。
- **两个偏离原建议之处**（都写进了条目）：
  1. 缓存没放进 `subjectrank.Query`：Redis 段 `Get` 回来的是 JSON 解码后的通用形状，
     在 `Query` 里做 `cached.([]Item)` 会**测试全命中、生产全落空**，且没有任何一处报错。
  2. 只缓存行，不缓存 `sources`/`medias`（那两个下拉每次现取）；陈旧只在榜的计数上，
     由响应新增的 `cache_ttl_sec` 说出来。
- **用例与变异**：四条（命中不重算 / 键带身份段 / `<=0` 回到真算 / `sources` 保持现取）。
  变异五次，读数如实记：**摘写入 → ①④ 两条同时红**（④ 以"命中"为前提）；删 `media` 段 → ① 红；

## 23. 表头被整行推下 64 像素：维护者点名的一格，一处只有"量一次"才现形的错

维护者的报法很准：「所有表格的标头标题都下移了，导致表头与表格第一行出现部分重叠」。
指向本场 §22 之前那颗 `3941534`「全局表头吸顶」。

- **现场读数**（临时实例 + 无头浏览器量几何，不是看图猜）：`/admin/users` 的表头相对**自己那一行**偏下 `shift=64`、
  压住第一行 `overlap=64`；把页面往下滚 600px 之后 `thTop=343` 而顶栏下沿=69——**它一次也没吸住过**。
  也就是说那颗提交带出去的只有副作用，主效果从没成立过。
- **真因是判据页那一行 ② 的同一条 CSS 规定换了受害者**（受害者从"越界"换成"画歪"）：
  `.table-wrap` 的 `overflow-x-auto` 让表格卡片成为 `th` 最近的**滚动口**，而 sticky 的 `top` 相对滚动口量、不相对视口；
  这个滚动口自己不纵向滚，于是 `top: 64px` 只剩下"把整行表头往下推 64 像素"这一半效果。
- **第一版修法**：把 `position: sticky` 从 `.table-base th` 上摘掉（`z-index` 一起摘——static 元素上它本来就不参与层叠）。
  **当时没有顺手改成"能吸住"的形态**：那要求给 `.table-wrap` 一个 `max-height` 让卡片自己纵向滚，
  等于把面板每张长表变成内滚区（滚轮捕获、双滚动条），那是**改交互口径**，等维护者点头，不由我捎带做掉。
- **维护者随后点了头（"要，做成卡片内滚动区" + "现在发"）**，于是两半一起做掉：
  `th` 恢复 sticky 但 `top: 0`（**相对滚动口给偏移，所以只能是 0**）、底色要落在 `th` 上而不是只靠 `thead`
  （粘住之后 thead 的底色跟着内容滚走，行会从字底下穿过去），另一半是文件末尾新增那条
  `@media (min-width: 768px) { .table-wrap { max-height: calc(100vh - 9rem); overscroll-behavior: contain } }`。
  **窄屏刻意不给 `max-height`**：小屏切一块矮滚动区比页面变长更糟，而 `top: 0` 在那里只是不吸顶、不会把表头推走。
  `9rem` 不是契约（粘性顶栏实测 69px + 页面留白 + 页标题那一行的近似），探针验的是"滚起来之后 th 还贴着卡片顶边"。
- **两次变异各挡一半**（这一格的第二种比第一种重要——它挡的是"检查自己变成摆设"）：
  ① `top` 改回 64px → `/admin/users` 与 `/admin/roles` 双双 `shift=64、overlap=64` 红；
  ② 把 `max-height` 摘掉而 sticky 留着 → 探针报「带 STICKY=1 跑，但没有任何一张表格卡片滚起来——吸顶那半没被验过」红。

  1280 档那两张 20 行的长表 `滚后 thTop−口顶=1`（那 1px 是卡片边框）、其余短表如实报"这张卡没纵滚"，390 档全部 `shift=0 overlap=0`。
